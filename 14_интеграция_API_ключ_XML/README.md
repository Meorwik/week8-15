# 14. API с ключом, JSON/XML и веб-клиент

Доработал API из 8 занятия: ключ в заголовке X-API-Key, ответ в JSON или XML и полнотекстовый поиск /search. client.html открывается на главной странице, client.py делает те же запросы через requests. Нужны переменные DATABASE_URL и API_KEY, проверки в output.txt и postman_collection.json.
