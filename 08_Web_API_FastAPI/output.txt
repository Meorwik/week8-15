== Маршруты в /docs (из /openapi.json)
GET /titles/top
GET /titles/{title}
POST /checkouts
PUT /checkouts
DELETE /checkouts

== 1. Топ за 2019
$ curl http://127.0.0.1:8008/titles/top?year=2019&limit=5

-> HTTP 200

== 2. Выдачи по названию
$ curl http://127.0.0.1:8008/titles/Spinning%20silver
[{"title_id":2725,"title":"Spinning silver / Naomi Novik.","year":2019,"month":1,"material_type":"BOOK","checkouts":388}]
-> HTTP 200

== 3. POST: добавить выдачу
$ curl -X POST http://127.0.0.1:8008/checkouts -H content-type: application/json -d {"title_id":2725,"year":2020,"month":5,"material_type":"BOOK","checkouts":7}
{"fact_id":5009,"title_id":2725,"year":2020,"month":5,"material_type":"BOOK","checkouts":7}
-> HTTP 201

== 4. POST: month=13
$ curl -X POST http://127.0.0.1:8008/checkouts -H content-type: application/json -d {"title_id":2725,"year":2020,"month":13,"material_type":"BOOK","checkouts":7}
{"detail":[{"type":"less_than_equal","loc":["body","month"],"msg":"Input should be less than or equal to 12","input":13,"ctx":{"le":12}}]}
-> HTTP 422

== 5. POST: несуществующий title_id (ForeignKeyViolation -> 404, а не 500)
$ curl -X POST http://127.0.0.1:8008/checkouts -H content-type: application/json -d {"title_id":999999,"year":2020,"month":5,"material_type":"BOOK","checkouts":7}
{"detail":"Название с title_id=999999 не найдено"}
-> HTTP 404

== 6. PUT: изменить число выдач
$ curl -X PUT http://127.0.0.1:8008/checkouts -H content-type: application/json -d {"title_id":2725,"year":2020,"month":5,"material_type":"BOOK","checkouts":12}
{"title_id":2725,"year":2020,"month":5,"material_type":"BOOK","checkouts":12}
-> HTTP 200

== 7. DELETE
$ curl -X DELETE http://127.0.0.1:8008/checkouts?title_id=2725&year=2020&month=5&material_type=BOOK
{"deleted":{"title_id":2725,"year":2020,"month":5,"material_type":"BOOK"}}
-> HTTP 200

== 8. DELETE повторно
$ curl -X DELETE http://127.0.0.1:8008/checkouts?title_id=2725&year=2020&month=5&material_type=BOOK
{"detail":"Запись о выдаче не найдена"}
-> HTTP 404

== Доп.: топ без обязательного year
$ curl http://127.0.0.1:8008/titles/top?limit=5
{"detail":[{"type":"missing","loc":["query","year"],"msg":"Field required","input":null}]}
-> HTTP 422
