# 8. Web API для базы данных

API на FastAPI поверх seattle_library: топ названий за год, поиск по названию и добавление/изменение/удаление выдач, функции работы с базой в db.py. Запуск: задать DATABASE_URL и выполнить `uvicorn api:app --reload`, коллекция для Postman лежит в postman_collection.json. Ответы на все запросы сохранил в output.txt.
