# 13. Облачная база данных

migrate_to_cloud.py создаёт таблицы в Neon, копирует данные через COPY, сверяет количество строк и меряет время запроса локально и в облаке. Строка подключения берётся только из переменной CLOUD_DSN, файл .env в гит не попадает. Облако вышло медленнее локальной базы: 1843 мс против 8 мс, потому что сервер в США (пинг около 205 мс) и на каждый запрос заново открывается соединение.
