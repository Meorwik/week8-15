# 13. Облачная база данных

migrate_to_cloud.py создаёт таблицы в облачной базе, копирует данные через COPY, сверяет количество строк и меряет время запроса локально и в облаке. Строка подключения берётся только из переменной CLOUD_DSN, файл .env в гит не попадает. В output.txt пока прогон на втором локальном контейнере, с Neon перезапущу.
